## Featured Projects

### [Supply Chain Performance Command Center](https://github.com/YashLadlapure/supply-chain-command-center)
PostgreSQL schema, 24 SQL KPI queries, 12 data-quality checks and a Power BI report on delivery performance, inventory risk and supplier performance.
It also has an "Ask the data" tool that turns plain-English questions into read-only SQL behind a query guard. In my scored evaluation, answerable questions went from 7/30 to 26/30 with retrieval, and all 5 unsafe requests were refused ([results](https://github.com/YashLadlapure/supply-chain-command-center/blob/main/docs/rag-eval.md)).

`Python` `PostgreSQL` `SQL` `Power BI` `RAG`

### [F1 Race Pace Dashboard](https://github.com/YashLadlapure/F1-Race-Pace-Dashboard)

`Python` `pandas` `Tableau`
